# setup

Initialize or verify project setup.

## Prerequisites

Read the project-setup skill at `.agents/skills/project-setup/SKILL.md`.

## Instructions

1. Check what already exists in the project
2. Identify missing or misconfigured files
3. Either:
   - For new projects: create standard files based on user's stack choice
   - For existing projects: report what's missing or needs attention

## Output

Report:
- What exists and is correctly configured
- What's missing
- What needs attention
- Suggested next steps

Do not make changes without user confirmation.
