# Document Review

Review the provided markdown document for:

## Structure
- Is there a clear introduction?
- Are sections logically organized?
- Are headings used appropriately?
- Is there a conclusion or summary if needed?

## Clarity
- Is the language clear and concise?
- Are technical terms explained?
- Are examples provided where helpful?

## Completeness
- Are all necessary topics covered?
- Are there obvious gaps?
- Are action items or next steps clear?

## Formatting
- Is markdown syntax used correctly?
- Are lists, code blocks, and tables formatted properly?
- Are links working and descriptive?

## Output

Provide:
1. A brief overall assessment
2. Specific suggestions grouped by category
3. Examples of improved text where applicable
