# implement-and-review

Implement an approved plan with TDD, then review the working tree.

## Instructions

Read and follow the implement-and-review skill at `.agents/skills/implement-and-review/SKILL.md` exactly as presented.

The skill will guide you through:

1. Requiring a `docs/plans/` implementation plan
2. TDD (red → green) per plan task
3. Code-review only after the last task

## Important

- Do NOT skip TDD
- Do NOT treat self-review as a substitute for the code-review skill
- Do NOT commit or push unless asked
