# grill-spec

Grill a feature idea, then write a spec under `docs/specs/`.

## Instructions

Read and follow the grill-spec skill at `.agents/skills/grill-spec/SKILL.md` exactly as presented.

The skill will guide you through:

1. Grilling until shared understanding
2. Writing `docs/specs/YYYY-MM-DD-<name>.md`
3. Stopping before plan or code

## Important

- Do NOT plan or implement in this command
- Specs live in `docs/specs/`, not `docs/plans/`
