# feature-dev

Run the full feature loop: grill spec → plan → plan-verifier Pass 1 → TDD implement → code-review.

## Instructions

Read and follow the feature-dev skill at `.agents/skills/feature-dev/SKILL.md` exactly as presented.

The skill will guide you through size-gating, grilling a spec into `docs/specs/`, writing a plan, verifying spec coverage, implementing with TDD, and reviewing.

## Important

- Do NOT skip grill-spec, plan-verifier Pass 1, TDD, or code-review on a real feature
- Specs live in `docs/specs/`; plans live in `docs/plans/`
- Do NOT implement until Pass 1 coverage is accepted
